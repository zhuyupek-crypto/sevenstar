## 3. 预测目标定义

### 3.1 主目标（连续值）

```text
target_excess_Nd = future_return(C8D_baseline, N) - future_return(O7_baseline, N)
```

- `target_excess_Nd > 0`：未来 N 日 C8D 优于 O7
- `target_excess_Nd < 0`：未来 N 日 O7 优于 C8D

### 3.2 辅助目标（二分类）

```text
target_win_Nd = 1 if target_excess_Nd > 0 else 0
```

### 3.3 预测窗口

- **主窗口**：N = 20
- **辅助窗口**：N = 5 / N = 60

### 3.4 未来收益计算口径（P3-02 修正版）

```python
roll = (1 + daily_return).rolling(N).apply(np.prod, raw=True) - 1
future_return_Nd = roll.shift(-(N - 1))   # T 到 T+N-1 的未来 N 日累计收益
```

**严禁再次使用未 shift 的 rolling 过去收益**（P3-02 致命 bug 教训）。

### 8.1 MR score（均值回归倾向分数）

mr_score = z(-c8d_dd_120d) + z(-c8d_amt_change) + z(-c8d_vol_expansion)

| IC | 0.0207（弱正） |
| rank IC | -0.0059（近零） |
| H-L spread | 0.0130 |
| 一致年份 | **4/7**（未达 5/7） |

**结论**：MR score 未达到 5/7 稳定性门槛，**不通过**。主要拖累来自 2023（IC=-0.3638）和 2024（IC=-0.6679）两年严重反向。

### 8.2 relative_score（相对优势组合）

```python
relative_score = z(dd_diff_120d) + z(-vol_expansion_diff)
               + z(-amt_change_diff) + z(efficiency_diff)
               + z(-dispersion_diff)
```

原始假设：relative_score 越高，C8D 相对 O7 的状态越可能改善（C8D 越可能占优）。

| 指标 | 值 |
|------|---|
| IC | **-0.1197**（负，与原始假设方向相反） |
| rank IC | -0.1118 |
| H-L spread | **-0.0237**（高桶比低桶 target 更负 2.37%） |
| 一致年份 | **5/7** |
| 2026H1 方向 | ✓（IC=-0.2371，与全样本方向一致） |
| hit rate | 0.6137 |

**关键发现**：relative_score 达到 5/7 稳定性，但 **IC 方向为负**，与原始假设"越高 C8D 越占优"相反。

### 8.3 relative_score 方向反转的因果解读

实际数据表明：**relative_score 越高（C8D 相对 O7 状态越好），C8D 反而越可能输**。可能的因果解释：

1. **均值回归**：C8D 相对状态已经"好"时（回撤更浅、波动更稳、效率更高），往往意味着 C8D 近期已经上涨，后续面临回归
2. **O7 趋势持续**：O7 的强势（如 2026H1 原油驱动）具有持续性，C8D 的相对优势难以持续
3. **状态指标是滞后信号**：相对状态改善是结果而非原因，用滞后状态预测未来收益存在均值回归陷阱

**重要声明**：本报告严格遵守"不根据全样本结果事后改方向"的边界。relative_score 的原始方向假设是"越高 C8D 越占优"，实际检验为"越高 C8D 越输"。如需反向使用，必须在 P4-03 中先验证反向逻辑的因果合理性，而非直接反向。

2. **efficiency_diff** 在 N=5 时方向反转，稳健性存疑
3. **relative_score** 在 N=20 和 N=60 均达到 5/7，但 N=5 方向反转——短期预测力不稳定，中长期预测力更稳定
4. **mr_score** 在 N=20 未达 5/7，不通过

## 12. 是否达到 5/7 稳定标准

### 12.1 通过标准逐条检查

| 通过标准 | 结果 | 详情 |

## 13. 是否建议进入 P4-03

### 13.1 支持进入 P4-03 的理由

1. relative_score 达到 5/7 稳定性门槛（N=20 和 N=60 双重验证）
2. 2026H1 方向正确，无严重反向风险

4. strategy target 比 equal-weight target 更稳定（3:1 优势）

6. 多个变量显示一致的"均值回归"模式（成交额扩张→后续 C8D 输，头部拥挤→后续 C8D 输）

### 13.2 反对进入 P4-03 的理由

1. **relative_score 方向与原始假设相反**——这意味着我们对"什么时候 C8D 占优"的因果理解是错的
2. **IC 普遍较弱**：最强 |IC|=0.1359（efficiency_diff），relative_score |IC|=0.1197，属弱信号
3. **2024 全面牛市时多个变量失效**：均值回归类信号在单边牛市中可能持续失效
4. **N=5 短期预测力不稳定**：relative_score 在 N=5 方向反转，短期切换可能不可靠
5. **6/7 通过变量的 H-L spread 均 < 2.5%**：经济意义有限，切换收益可能被交易成本吞噬

### 13.3 建议

**有条件建议进入 P4-03**，但 P4-03 必须遵守以下严格前提：

1. **P4-03 必须先验证反向逻辑的因果合理性**：relative_score 实际方向为负（越高 C8D 越输），P4-03 必须先回答"为什么 C8D 相对状态好时反而后续会输"——是均值回归？是 O7 趋势持续？还是状态指标滞后？
2. **P4-03 不得直接反向使用 relative_score**：必须先有因果论证，再决定是否反向
3. **P4-03 应优先研究 o7_internal_corr_60d**：唯一 7/7 一致的变量，且方向与假设一致（正），因果逻辑更清晰（O7 拥挤→C8D 受益）
4. **P4-03 必须考虑交易成本**：H-L spread 2.37% 在扣除双边交易成本后可能所剩无几
5. **P4-03 必须验证 2024 类似环境的稳健性**：2024 全面牛市时多个变量失效，P4-03 需识别并处理此类环境
6. **P4-03 仍不生成切换规则**：只验证"反向逻辑是否因果成立 + 交易成本调整后是否仍有净收益"
