## 0. 修正说明：T-1 口径修复

### 0.1 修正原因

P4-02 原版（commit `11d3d9d`）的 `build_feature_panel()` 构建的是"T 日收盘后可计算"特征，而 P4-02 任务书要求"全部特征必须 T-1 可计算"。

原版问题：
- `feature[T]` 使用了 T 日 close/amount/return
- `target[T]` 包含 T 到 T+N-1 的未来收益
- 这导致 `feature[T]` 与 `target[T]` 共享 T 日信息，产生**同日信息污染**

### 0.2 修正方法

在 `build_feature_panel()` 末尾所有特征计算完成后，统一做：

```python
features = features.shift(1)
```

含义：
- `feature_panel.loc[T]` 只使用截至 T-1 的 close/amount/return/corr/dd/vol/efficiency 信息
- `target_panel.loc[T]` 使用 T 到 T+N-1 的未来收益
- 严格避免同日信息污染

### 0.3 修正范围

只改特征面板的时间口径，**不改**：
- O7/C8D 池定义
- target 定义
- N=5/20/60
- relative_score / mr_score 公式
- 单变量检验方法
- 年度稳定性标准
- 输出文件结构

### 0.4 target 不变

target_panel 完全不变（target 本身就是未来收益，无需 shift）。修正前后 target 统计完全一致：
- 总样本：1560 交易日
- target_excess_20d 均值：-0.0085
- target_excess_20d 标准差：0.0757
- target_win_20d 正样本占比：0.4487

## 3. 预测目标定义

### 3.1 主目标（连续值）

```text
target_excess_Nd = future_return(C8D_baseline, N) - future_return(O7_baseline, N)
```

- `target_excess_Nd > 0`：未来 N 日 C8D 优于 O7
- `target_excess_Nd < 0`：未来 N 日 O7 优于 C8D

### 3.2 辅助目标（二分类）

```text
target_win_Nd = 1 if target_excess_Nd > 0 else 0
```

### 3.3 预测窗口

- **主窗口**：N = 20
- **辅助窗口**：N = 5 / N = 60

### 3.4 未来收益计算口径（P3-02 修正版）

```python
roll = (1 + daily_return).rolling(N).apply(np.prod, raw=True) - 1
future_return_Nd = roll.shift(-(N - 1))   # T 到 T+N-1 的未来 N 日累计收益
```

mr_score = z(-c8d_dd_120d) + z(-c8d_amt_change) + z(-c8d_vol_expansion)

|------|-------|-------|------|

**结论**：MR score 未达到 5/7 稳定性门槛，**不通过**。修正后更不稳定（4/7 → 3/7）。

### 8.2 relative_score（相对优势组合）

```python
relative_score = z(dd_diff_120d) + z(-vol_expansion_diff)
               + z(-amt_change_diff) + z(efficiency_diff)
               + z(-dispersion_diff)
```

原始假设：relative_score 越高，C8D 相对 O7 的状态越可能改善（C8D 越可能占优）。

| 指标 | 修正前 | 修正后 | 变化 |
|------|-------|-------|------|
| IC | -0.1197 | **-0.1372** | 更强（负方向） |
| rank IC | -0.1118 | -0.1201 | 更强 |
| H-L spread | -0.0237 | **-0.0255** | 更强（负方向） |
| 一致年份 | 5/7 | **5/7** | 持平 |
| 2026H1 方向 | ✓ | ✓ | 持平 |
| hit rate | 0.6137 | — | — |

**关键发现**：relative_score 在 T-1 修正后**仍 5/7 一致，且方向仍为负（与原始假设相反）**，IC 从 -0.1197 增强到 -0.1372。说明 relative_score 的反向预测力不是同日信息污染造成的伪信号，而是真实的均值回归效应。

### 8.3 relative_score 方向反转的因果解读

实际数据表明：**relative_score 越高（C8D 相对 O7 状态越好），C8D 反而越可能输**。可能的因果解释：

1. **均值回归**：C8D 相对状态已经"好"时，往往意味着 C8D 近期已经上涨，后续面临回归
2. **O7 趋势持续**：O7 的强势（如 2026H1 原油驱动）具有持续性，C8D 的相对优势难以持续
3. **状态指标是滞后信号**：相对状态改善是结果而非原因，用滞后状态预测未来收益存在均值回归陷阱

**重要声明**：本报告严格遵守"不根据全样本结果事后改方向"的边界。relative_score 的原始方向假设是"越高 C8D 越占优"，实际检验为"越高 C8D 越输"。如需反向使用，必须在 P4-03 中先验证反向逻辑的因果合理性。
