**冻结结论：**


**关键发现：**

1. relative_score 低频化后信号**实质性消失**：A1 月度框架年化 8.08 次切换，但 50 次切换中绝大多数是"切换-1 天后切回"的无效切换，扣成本后累计跑输 O7 15.56pp。

## 第 3 章 低频框架定义

P4-04 只验证 4 个框架，不新增第 5 类。

### 3.1 框架 A1：月度 relative_score 反向框架

**逻辑**：relative_score 越低 → C8D 相对更可能占优 → 下月持有 C8D；否则持有 O7。

**频率**：每月最后一个交易日收盘后生成信号，下一交易日生效，整月不再切换。

**阈值**：relative_score ≤ 历史滚动三分位低阈值（1/3 分位）→ C8D。
- 滚动窗口：252 个交易日（min_periods=252）
- 不足 252 日时默认 O7
- 只用历史数据，禁止全样本分位数和未来数据

### 3.2 框架 A2：月度 o7_internal_corr_60d 框架

**逻辑**：O7 内部相关性越高 → C8D 分散价值越凸显 → 下月持有 C8D；否则持有 O7。

**阈值**：o7_internal_corr_60d ≥ 历史滚动三分位高阈值（2/3 分位）→ C8D。

其他要求同 A1。

### 3.3 框架 B1：月度双信号确认框架

**逻辑**：只有 relative_score ≤ 低三分位 **且** o7_internal_corr_60d ≥ 高三分位同时满足，才切到 C8D；否则持有 O7。

**设计目的**：relative_score 识别 C8D 相对低位，o7_corr 识别 O7 拥挤，两个信号同时满足才允许离开 O7。

**约束**：年化切换次数必须 ≤12，否则该框架直接判定失败。

### 3.4 框架 C1：季度双信号确认框架

**逻辑**：与 B1 相同，但只在 3/6/9/12 月最后一个交易日判断，整个季度不再切换。

**约束**：年化切换次数理论上 ≤4，若因窗口拼接或异常导致 >4 必须解释。

## 第 5 章 回测规则与成本扣减

### 5.1 初始持仓

默认 O7_baseline。

### 5.2 信号生效

```text
信号在月末 / 季末收盘后生成；
下一个交易日开始切换；
避免同日信息。
```

### 5.3 持仓选择

每日组合净值收益来自当前持有池：

- 持有 O7 → 使用 O7_baseline 当日收益
- 持有 C8D → 使用 C8D_baseline 当日收益

### 5.4 切换成本

每次池切换扣单边成本（与 P4-03 的 round-trip 静态测试不同，P4-04 是真实路径，按每次实际切换扣 single_side_cost）：

| 档位 | single_side_cost | round_trip 等价 |
|------|------------------|-----------------|
| low  | 0.10%            | 0.20%           |
| mid  | 0.20%            | 0.40%           |
| high | 0.37%            | 0.74%           |

切换当日组合净值额外扣除 `single_side_cost`。例如某日从 O7 切到 C8D，当日净值 = (1 + O7 当日收益) × (1 - 0.002)（mid 档）。

### 5.5 不允许额外调仓

低频切换只决定 O7 或 C8D，不改变 O7/C8D 内部策略逻辑。

### Q1. 低频切换后，是否有任何方案跑赢 O7_baseline？

**否。** mid 档无任何方案跑赢 O7_baseline。唯一跑赢的是 B1 low（+0.66pp），但 mid 档即转负（-0.63pp），跑赢空间完全被成本吞噬。

### Q2. 是否有方案在中成本档达到 5/7 窗口跑赢 O7？

**否。** A1/A2/B1 mid 档都是 0/7 窗口跑赢 O7。C1 mid 零切换等于 O7，不算跑赢。

### Q3. 是否有方案全区间收益高于 O7？

**mid 档无。** 仅 B1 low 全区间收益 61.43% > O7 60.77%（+0.66pp），但 mid 档即转负。

### Q4. 是否有方案最大回撤不高于 O7？

**是，全部方案。** 所有方案最大回撤都等于 O7 的 -59.68%，因为低频切换持有期极长，绝大部分时间持有 O7，回撤由 O7 主导。

### Q5. 年化切换次数是否 ≤12？

**是，全部方案。** A1=8.08，A2=2.58，B1=1.29，C1=0，都 ≤12。

### Q6. 成本扣减后，收益是否仍有经济意义？

**否。** 所有 mid 档方案扣成本后超额收益为负：A1 -15.56pp，A2 -3.79pp，B1 -0.63pp，C1 0pp。无经济意义。

### Q7. 2024 年是否拖累？

**仅 A1 high 明显拖累**（-6.88pp，触发"明显拖累"阈值）。A1 mid 接近阈值（-4.90pp）。A2/B1/C1 在 2024 零切换，未拖累但也未跑赢。

### Q8. 2026H1 是否拖累？

**否。** 所有方案在 2026H1 未明显拖累。A1 轻微拖累 0.64pp（2 次切换），A2/B1/C1 零切换等于 O7。

### Q9. relative_score 低频化后是否仍有效？

**否，实质性消失。** A1 月度框架虽然触发 50 次，但中位持有仅 10 天，是"切换-1 天后切回"的噪声触发。扣成本后跑输 O7 15.56pp。relative_score 的反向逻辑在静态分桶下成立（P4-03 冻结），但在动态路径下失效。

### Q10. o7_internal_corr_60d 低频化后是否仍有效？

**否，几乎不触发。** A2 月度框架 6.5 年仅触发 16 次（年化 2.58），全部集中在 2022 和 2025。2024 失效环境零触发。扣成本后跑输 O7 3.79pp。o7_internal_corr_60d 的 7/7 一致性在静态分桶下成立（P4-03 冻结），但低频化后无法捕获。

### Q11. 双信号确认是否优于单信号？

**是，但仍不够。** B1（8 次切换，-0.63pp）优于 A1（50 次，-15.56pp）和 A2（16 次，-3.79pp）。双信号确认有效减少了切换次数和成本，但 8 次切换全部集中在 2022 年，是单一年份贡献，不满足"逻辑可解释，非单一年份"。

### Q12. 月度是否优于季度？

**月度有切换，季度无切换。** C1 季度框架从未触发，等于持有 O7。月度框架至少有切换尝试，但仍未跑赢 O7。从"信号捕获"角度月度优于季度；但从"扣成本后收益"角度两者都未跑赢 O7。

### Q13. 高成本档是否全部失效？

**否。** B1 high 收益 57.97% > O7 95%×60.77%=57.73%，通过 95% 阈值。C1 high = O7。但 A1 high (33.34%) 和 A2 high (52.76%) 都未通过 95% 阈值。

### Q14. 是否应进入 P4-05？

**否。** 无方案满足全部 10 项通过标准，3 项终止条件触发。任务书明确"只有在 mid 档满足全部 10 项时才允许建议进入 P4-05"。

### Q15. 是否应停止 O7 vs C8D 池切换研究？

**是。** 触发 3 项停止条件：
1. 无方案全区间跑赢 O7_baseline（排除零切换）
2. 无方案达到 5/7 窗口跑赢 O7（排除零切换）
4. 年化切换 ≤12 且有切换的方案无一个跑赢 O7

P4-03 的机械切换证伪 + P4-04 的低频切换证伪，共同证明 O7 vs C8D 的相对状态信号无法支撑可交易的切换策略。

### Q16. 当前最终 baseline 是否仍为 O7_baseline？

**是。** O7_baseline 继续作为最终保守 baseline（P4-01 冻结，P4-04 再次确认）。

```python
# 月末标记
s = pd.Series(features.index, index=features.index)
next_month = s.shift(-1).dt.to_period('M')
cur_month = s.dt.to_period('M')
is_month_end = next_month != cur_month
is_quarter_end = is_month_end & s.dt.month.isin([3, 6, 9, 12])

# 滚动三分位阈值（min_periods=252）
rel_low_q = rel_score.expanding(min_periods=252).quantile(1.0/3.0)
corr_high_q = o7_corr.expanding(min_periods=252).quantile(2.0/3.0)

# A1: 月末 relative_score <= 滚动低三分位 → 下月 C8D
a1_trigger = is_month_end & (rel_score <= rel_low_q) & rel_low_q.notna()
a1_signal = a1_trigger.shift(1).ffill().fillna('O7')  # 下一交易日生效

# A2: 月末 o7_corr >= 滚动高三分位 → 下月 C8D
a2_trigger = is_month_end & (o7_corr >= corr_high_q) & corr_high_q.notna()

# C1: 季末判断，条件同 B1
```

### C.2 真实切换回测

```python
def backtest_switching(signal, o7_nav, c8d_nav, single_side_cost):
    """signal: 每日持有池（'O7' 或 'C8D'）"""
    nav = [1.0]
    current = 'O7'
    switch_events = []
    for i in range(1, len(signal)):
        today_hold = signal.iloc[i-1]  # T-1 信号决定 T 持仓
        ret = o7_nav.iloc[i] if today_hold == 'O7' else c8d_nav.iloc[i]
        cost = single_side_cost if today_hold != current else 0.0
        if cost > 0:
            switch_events.append({'date': signal.index[i], 'from': current, 'to': today_hold, 'cost': cost})
        nav.append(nav[-1] * (1 + ret) * (1 - cost))
        current = today_hold
    return nav, switch_events
```
