### 1.4 未来收益计算修正说明（关键）

**bug**（commit f6293db）：`rolling(n).apply(np.prod)` 计算的是截至当前日的过去 N 日滚动收益，而非未来 N 日收益。

**修正**：`rolling(n)` 在索引 `i` 处计算 `[i-n+1, i]` 的累计收益，用 `shift(-(n-1))` 将索引 `i+n-1` 处的值移到索引 `i`，得到 `[i, i+n-1]` 的真正未来 N 日收益。

```python
roll_risk = (1 + risk_ret).rolling(n).apply(np.prod, raw=True) - 1
future[f'risk_ret_{n}d'] = roll_risk.shift(-(n - 1))  # T 到 T+N-1 未来收益
```

### 1.5 双口径设计
- **主口径**：原风险池 7 只 vs 大池独有 30 只
  - 超额收益 = 大池独有等权 - 原风险池7等权
- **稳健性口径**：原风险池 7 + 防御 1 = 8 只 vs 大池独有 30 只
  - 超额收益 = 大池独有等权 - (原风险池7+防御1)等权
  - **防御 ETF 不参与大池独有 TopN 计算**（因子2/4 仅用 37 只风险 ETF）

## 4. 三阶段胜负的因子解释（结合 P3-01 归因）

### 4.1 早期（2020-2022）原池赢
- **因子5**：原池 Top2 强度 high 桶 -4.14%（2022），原池主题极强 → 大池输（方向性成立）
- **因子1**：2022 递增（high=+0.97%），但 2020/2021 非单调或递减 → 解释力不稳定
- **P3-01 印证**：大池独有宽基稀释收益，资金占比 50-58% 但收益仅 0.1%/0.4%/-0.06%

### 4.2 中期（2023-2025）大池赢
- **因子1**：2023 递增（high=+0.04%），但 2024 high=-0.68%（最差）、2025 非单调 → **因子1 无法解释中期大池赢**
- **因子2**：2023 递增，但 2024/2025 递减 → **因子2 无法解释 2024/2025 大池赢**
- **因子4**：2024 low=+2.44%（最优），呈反转模式 → 大池独有主题动量低时反而赢，与"主题共振"叙事矛盾
- **P3-01 印证**：2024 D 的 +1.25M 来自大池独有（中概互联+纳指+德国）

### 4.3 近期（2026H1）大池失效
- **因子5**：high=-2.70%（n=81），原池 Top2 极强 → 原池主题极强时应回避大池（方向性成立）
- **因子1**：high=+3.39%（n=17），但样本不足且全样本非单调 → 解释力弱
- **因子4**：low=+5.01%（n=6）最优，呈反转模式 → 主题动量低时反而好
- **P3-01 印证**：大池独有占 80% 资金但收益仅 0.33%，原池 0.94% 但只占 20% 资金

### 4.4 因子组合解释力（修正后）
- **早期原池赢** = 因子5（原池强 → 大池输）✓ 成立
- **中期大池赢** = 因子1/2/4 均无法稳定解释 ✗ 不成立
- **2026H1 失效** = 因子5（原池极强）✓ 部分成立

**关键事实**：未来收益修正后，因子1/2 失去预测力，因子4 显示反转模式，仅因子5 保留部分方向性。中期（2023-2025）大池赢的现象无法由这 4 个交易前因子解释。

| 因子5 | 7/7 或 5/7 一致，反向信号候选 | 4/7 递减，反向信号候选（唯一保留） | 方向性部分保留，但稳定性下降 |

### 6.2 关键修正说明
1. **因子1/因子2 的"7/7 年份一致"是伪信号**：过去收益与动量因子天然自相关（动量本身就是过去收益的函数），用过去收益做分桶自然会显示"动量高 → 过去收益高"。修正为未来收益后，这种自相关消失，因子1/2 失去预测力。
2. **因子4 显示均值回归**：主题动量高 → 未来超额为负，主题动量低 → 未来超额为正。这与"动量延续"的因子逻辑相反，提示大池独有主题存在过度上涨后的均值回归。
3. **因子5 是唯一保留方向性的因子**：原池强 → 大池独有未来跑输，4/7 年份成立。但 2024/2025 失效，稳定性不足以单独使用。
4. **中期（2023-2025）大池赢无法由交易前因子解释**：因子1/2 在 2024/2025 甚至显示反向，因子4 显示反转。中期大池赢可能由事后主题爆发（中概互联/纳指/德国）驱动，而非交易前可观察的动量信号。
